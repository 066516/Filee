Run ./Filee to test the extracted app, or ./filee-cli help for the command line.

Run ./install.sh to install for the current user. It requires Python 3, creates
an application launcher and ~/.local/bin/filee, and does not require root.
Run ./uninstall.sh to remove this installation and Filee-downloaded engines.
Your settings and converted files are kept. If integration cleanup fails, the
installation is kept so you can fix the error and run the uninstaller again.
An existing installation is never overwritten; uninstall it before replacing it.

Filee runs on Ubuntu 22.04 or newer and other distributions with glibc 2.35 or
newer. The .NET runtime is bundled; its native system libraries are still
required. Install the desktop and runtime dependencies with:

Ubuntu 24.04:
sudo apt-get install ca-certificates libc6 libgcc-s1 libgssapi-krb5-2 libicu74 libssl3t64 libstdc++6 tzdata zlib1g libfontconfig1 libfreetype6 libx11-6 libice6 libsm6 libxrandr2 libxkbcommon0 libxi6 libxtst6 libxt6 fonts-noto-cjk python3

Ubuntu 22.04:
sudo apt-get install ca-certificates libc6 libgcc-s1 libgssapi-krb5-2 libicu70 libssl3 libstdc++6 tzdata zlib1g libfontconfig1 libfreetype6 libx11-6 libice6 libsm6 libxrandr2 libxkbcommon0 libxi6 libxtst6 libxt6 fonts-noto-cjk python3

Later Ubuntu releases ship a newer libicu (find its name with apt-cache search
libicu). Other distributions use different package names. The desktop needs an
X11 server (or XWayland), fontconfig, FreeType and the X11 libraries above.
X11 supports the global gesture toolbar; it needs libXtst and libXt (libxtst6,
libxt6). A native Wayland session has additional input restrictions; use the
drop window and file-manager actions, or the experimental setup below.

Wayland gesture (experimental, KDE Plasma): Filee reads the mouse and keyboard
from /dev/input, which needs the input group, and a KWin script moves the donut
to the cursor because Wayland apps cannot place windows. Members of the input
group can read all keyboard and mouse input, so enable this only if you accept
that. Add yourself, then sign out and in:
  sudo usermod -aG input "$USER"
Then load the script (it lasts until you sign out):
  qdbus6 org.kde.KWin /Scripting loadScript "$HOME/.local/share/filee/application/filee-donut.js" filee-donut
  qdbus6 org.kde.KWin /Scripting start
Wayland cannot say which window is under the cursor, so any Ctrl+drag opens the
invisible donut window; it only shows when files are dragged onto it.
Packages are built and smoke-tested on Ubuntu 24.04 and started on Ubuntu 22.04
by the automated builds.

rhwp and 7-Zip are bundled. Other engines are installed from Filee settings or
discovered in the system. Format support depends on available native engines.
Optional engines can require additional system libraries. In particular, calibre
may require libxcb-cursor0, libxcb-xinerama0 and other Qt/XCB dependencies.
